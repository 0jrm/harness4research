# Agent notes

- Submit jobs only with `guard/run preflight <run_dir> <job_script>`, never `sbatch`. A job must fit `max_walltime_minutes` in `guard/budget.card`; split longer work into checkpointed jobs that resume.
- Before a run's first job, write `runs/<run_id>/question.card` from `runs/_template/question.card` and run `guard card add <run_id> <card file>`. Preflight refuses until it is approved.
- `guard/`, `AGENTS.md` and every path in `guard/watch.list` belong to the human. The remote refuses a push that edits them.
- To ask the human, run `guard needs-you add`.
- For a decision you would otherwise wait on, run `guard ask "<question>" --default <the safe option> --deadline 5m` (or 30m, 2h). It returns at once; if nobody answers in time, the default is taken.
- Finish by pushing to `main` on `origin`.
